I built a real-time polling app with FastAPI and WebSockets for my backend course.



The interesting part was managing multiple WebSocket connections at the same time.

I created a ConnectionManager class that keeps track of all connected clients and

broadcasts vote updates to everyone instantly when someone votes.



No page refresh, no polling — just a persistent connection that pushes updates live.



Tech: FastAPI, WebSockets, Docker, Python



GitHub: https://github.com/OzgurOzturk7/fastapi-journey/tree/oozturk-mini-project-4
